A design system built for a small coastal architecture studio. The token set draws from the palette of the studio's physical materials — stone, salt, and reclaimed timber.

Storybook documents every component in isolation; Sanity provides the content layer. The system is intentionally small: a handful of layout primitives, a type scale, and a colour ramp that works in print as well as on screen.
