A mobile notes app prototype built to test a specific interaction: typing a note should feel as fast and frictionless as dictating it. The UI is just a text input and a list, but the animation and keyboard handling are carefully tuned.

Built with Expo and React Native. The prototype exists to answer one design question; it hasn't shipped and probably won't. Sometimes that's what a prototype is for.
