Contributed to Armstrong, Rocketmakers' open-source React component library, used across the consultancy's client projects.

A shared library is a different discipline from a one-off feature: the APIs have to be predictable, accessible and flexible enough to survive a dozen different client designs. Alongside it, built React frontends for clients including Pure Planet, Sero and Wavesix, and wrote and delivered an HTML and CSS course for work-experience students.
